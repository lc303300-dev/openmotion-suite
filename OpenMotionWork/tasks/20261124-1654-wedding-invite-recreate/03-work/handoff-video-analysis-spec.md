## 5. 请输出的规格（编号对应，逐条给数值；不要写"渐显/淡入"这类无法编程的描述）

- **A1** 中文字体：具体字体家族判断（宋体/明朝系？哪一款最像），给出 3 个最接近的可替代字体（含可商用/开源选项）

- **A5** 四组文字是否有不透明度差异、混合模式或投影

### B. 字体动画（重点，逐段给）

对**每一组文字的入场和离场**分别给出：

- **B1** 触发时间：首帧 / 末帧（秒 + 帧号）
- **B2** 动画单位：整行 / 每字符 / 每词 / 每笔画？（逐帧确认，尤其 `欢迎参加我们的婚礼答谢午宴` 是否逐字）
- **B3** 每字符的初始状态分布：x 偏移范围、y 偏移范围、scale 范围、rotate 范围、opacity 范围，是否有 blur / 重影；是随机还是有索引规律（给规律）
- **B4** stagger：每字符延迟（秒）、进场顺序（左→右 / 乱序 / 按笔画）、相邻字符延迟差
- **B5** 运动曲线：最接近的 cubic-bezier 或 GSAP ease 名、单字符持续时长
- **B6** 是否有字距收敛（letter-spacing 从大到正常或反之）、行距变化、整体位移
- **B7** 是否叠加**乱码替换（scramble）**：若有，给乱码字符集特征、每字符替换频率（帧）、锁定顺序、是否同时伴随位置抖动
- **B8** 中文行与英文行的相对时序：谁先、相差多少毫秒
- **B9** 离场规格：运动方向规律（统一向上 / 向外辐射 / 随机）、每字符位移量、rotate、opacity 衰减曲线、stagger、总时长
- **B10** 停留期是否有 idle 动画（呼吸、微抖、字距呼吸）
- **B11** 入场中间态的"双层残影"究竟是什么：每字符独立偏移造成的视觉，还是真的存在两层文本（如描边层/残影层）？给出判定依据帧号

- **C5** 粒子：数量级、大小、颜色、运动（上飘 / 随机抖动）、闪烁频率、分布区域（是否只在光锥内）、有无模糊
- **C6** 全局：是否有轻微镜头呼吸 / 位移 / 缩放、暗角、纸面阴影、整体不透明度变化
