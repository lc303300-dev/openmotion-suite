# 任务模板（不要直接在这个目录里工作）

新建任务时：把本目录**复制**到 `tasks\<YYYYMMDD-HHMM>-<slug>\`，然后按需改名/填空。
也可以只复制骨架：`01-ref\ 02-assets\ 03-work\ 04-deliver\ 00-brief.md task.json`。

四个子目录的职责（不要混用）：

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `01-ref\` | 参考片原文件、抽帧、截图、分镜参考、继承来的素材 | 最终交付物、工程源码 |
| `02-assets\` | 准备导入工程的素材（图片/音频/字体/视频片段） | 原片参考、临时脚本 |
| `03-work\` | 脚本、分析产物、中间文件、交接文档 | 交付物 |
| `04-deliver\` | 导出 MP4、对比图、交付说明 | 中间产物 |

`00-brief.md`：需求与口径（人读）。`task.json`：机器可读状态（projectId/继承/导出记录）。
两个文件都必须写，且 `task.json` 的 `taskId` 必须等于目录名。
